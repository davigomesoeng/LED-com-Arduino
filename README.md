# Primeiro Programa — LED com Arduino
Projeto 4 — Introdução a microcontroladores, desenvolvido no Tinkercad.

## Objetivo
Conectar um LED ao Arduino e fazer ele funcionar através de um programa. Compreender a diferença entre circuito puro e circuito controlado por código.

## Montagem
- Placa: Arduino Uno
- LED (cor azul) + Resistor de 220 Ω
- Conectado ao Pino Digital 13
- Alimentação via USB

## Conceitos aprendidos
- O Arduino é um "cérebro programável"
- Pinos digitais podem ser configurados como SAÍDA (ligar/desligar)
- O código diz: quando ligar → acenda o LED
- Modificar um circuito existente é uma forma válida de aprender
